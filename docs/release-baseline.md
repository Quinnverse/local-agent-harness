# 工程基线与发行验收范围

本项目提供通用本地插件宿主、CLI和loopback Web。正式文本插件支持配置upper/lower；文件插件经宿主broker统计UTF-8文本的字节、逻辑行和空白词元。第三插件是独立文本反转示例。

源码工程基线已在先前独立解压中验证：18组自动化测试通过，真实浏览器完成两个正式插件安装/配置/启停/执行，真实CLI验证故障和超时进程回收，第三插件扩展前后src哈希相同。本说明是已发生的工程基线，不声称新发行压缩包已经完成最终复验。

本次发行只修复打包工具和交付文档。宿主src、原18组测试、正式插件业务代码及依赖锁文件不因包装修复而变化。新包在生成后必须重新解压，独立安装、构建、测试及浏览器操作；最终结果在同批交付的release-gate-report.md，绑定发行包SHA-256。

## 覆盖边界

测试按core8组、CLI1组、hardening8组和Web1组计数。多个失败场景仅断言结构化失败，部分hardening补充精确错误码。51ms用例允许超时，只验证参数接受。core对象重读和同进程写竞争不等同于宿主进程重启及跨进程压力测试。HTTP测试不执行浏览器DOM；发行验收必须单独进行真实浏览器操作和进程重启。

## 安全与平台

没有接入LLM，也没有确定性规则伪装模型推理。AgentAdapter只是未来类型接口。普通Node子进程不是操作系统沙箱，只允许可信插件；broker授权仅限制宿主读取API，不能禁止恶意插件直接访问操作系统。超时只保证直接执行进程回收，不保证恶意后代全部清理。

当前真实平台证据仅macOS/Node24。其他平台未验证。保留锁定依赖，依赖安全告警不因重新打包自动消失；具体审计错误、版本、直接/传递关系及实际选项由最终报告披露，不宣称未经验证的漏洞修复。
